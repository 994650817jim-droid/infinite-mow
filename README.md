# 三国：乱世千军

三国题材、手机竖屏 H5 Roguelike 割草游戏，使用 TypeScript、Phaser 3 和 Vite。

## 当前内容

- 第一章《黄巾之乱》：六波敌军与张角。
- 第二章《虎牢关之战》：八波敌军、西凉军与吕布。
- 赵云、关羽、黄忠、诸葛亮，以及四名武将的专属被动。
- 武器升级、遗物、流派、友军招募和触控摇杆。

当前为开发试玩版，仍在进行真机性能与战斗平衡验证。

## 本地运行

需要 Node.js 22 与 npm。

```sh
npm ci
npm run dev
```

打开终端显示的地址。手机与电脑在同一局域网时，可使用电脑的局域网地址访问。

## 正式构建

```sh
npm run build
npm run preview
```

正式文件输出至 `dist/`。开发调试场景和测试面板不进入正式构建。

## GitHub Pages

仓库 Settings → Pages → Source 选择 GitHub Actions。推送至 `main` 后，`.github/workflows/pages.yml` 会构建并发布 `dist/`；也可从 Actions 手动执行。

保留 Vite 相对资源路径 `base: './'`，支持仓库子目录访问。分享链接时保留末尾 `/`，不要把 `src/` 或开发服务器直接作为公网发布目录。
