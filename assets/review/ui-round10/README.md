# UI 第 10 轮：武将谱「战法心得」页重排（只做电脑布局）

用户原话：「这里ui很乱」。

## 改前的问题（before-desktop-xinde.png）
- 铁壁有 4 个战法，第 4 张「以战养战 · 解锁」溢出到右列，压住「军令」分类名；
- 按钮宽度固定，长名字（破阵重击 · 解锁 等）被缩小字号，大小不一；
- 两列 8 个分类挤在上半屏，下半屏空着；
- 已选 / 已解锁 / 未解锁只靠「· 解锁」后缀区分。

## 改后
- 每个分类一行（8 行）占满面板高度；分类名在左列，旁边写已解锁数（如 2/4）。
- 战法卡统一宽度（放得下最长的「以战养战」+ 锁 + 价格）、统一 14px 字号，不再缩放；互不重叠，也不压分类名。
- 三种状态：已选心得 = 朱红底金边 + ✓；已解锁可选 = 漆底金边；未解锁 = 暗底灰边 + 锁 + 「6 残卷」（残卷够时金字，不够时暗红）。
- 悬停：卡边变亮，底部说明栏显示战法效果和点击后会怎样（选为心得 / 取消 / 心得已满 / 花几残卷解锁）；解锁或选择的结果提示也显示在说明栏里。
- 解锁、选心得的逻辑没动；属性页没动；手机布局沿用原样。

## 检查
- `tools/ui-round10-xinde.mjs`（1280×720、960×540）：25 张战法卡、互不重叠不压分类名、字号统一不缩放、8 行、悬停显示效果，全部通过，无控制台错误。
- `tools/test-hero-codex.mjs` 11/11 通过。
