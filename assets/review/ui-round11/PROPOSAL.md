1. **装束图（重点：「穿在人身上」）**：全身厚涂立绘（epic-home 那套，已有 12 张透明底）居中站在卷轴纸底上；
   左侧 头盔 / 甲胄 / 信物 / 坐骑，右侧 遗珍 / 信物二 / 战靴，每个槽用一条细金虚线引到身体对应部位（头、胸、腰间玉佩、脚、马镫）。
   槽位旁竖排朱红小牌写槽名；空槽显示墨线剪影（头盔、甲、靴、玉佩、马、宝匣），锁住的槽右下角挂锁牌。
2. **将印切换**：顶部 12 枚圆形将印（立绘头像）代替文字按钮；选中的描金发光，下面小字写名字。
3. **品质框**：五档各一张厚涂边框——白：素铜；绿：青玉；蓝：青金石；紫：紫晶；橙：鎏金带火光。四角镶对应宝石，越高品质越亮。
4. **行囊盘**：深色漆木托盘；筛选改成带小图标的页签（全部 / 甲胄 / 头盔 / 战靴 / 信物 / 遗珍）；空格是浅浅的凹槽。
   角标保留：「新」（本局缴获）、穿戴者首字（如「关」）。
5. **悬停卡**：漆底金边，顶部一条品质色渐变带放图标、名字、品质 · 槽位；下面词条；虚线下是与当前穿戴的对比（▲ 绿 / ▼ 红）。
   详情卡（点道具弹出）、马厩、旧物卡同一套卡面。
6. **兵装加成**：立绘下方一条横幅，四列词条 + 右上角 ★ 特效名。
