# UI 第 12 轮：主页精简 + 章节选择（电脑布局，1280×720 / 1920×1080）

用户原话：「我想优化调整一下游戏界面ui，不需要太多字，和点击匡扶汉室，可以进入章节选择，但是之前没打过就只能选择打到哪个章节」。

## 主页（电脑版，手机版不变）
- 留：「三 国 / 乱世千军」、武将立轴、「匡扶汉室」、底排 存档 · 图鉴 · 战役回顾 · 设置、右上 成就 / 天下地图 / 营寨。
- 去掉：标题下题词、右侧章名 / 关名 / 简介和读字暗晕、「新篇揭晓」；立轴上去掉称号竖列、题句、天赋、武艺小字（只留名字、阵营印、定位印、兵器）。主页文字从 12–13 条减到 8 条。
- 功能都还在：章节进度改在章节选择里看；武将详情在「图鉴」与更换武将里。

## 章节选择（`src/ui/ChapterSelect.ts`）
- 点「匡扶汉室」打开「择章」：十二章 6×2，卡面是天下地图上该章地域的一角（现有厚涂地图）、朱印章序、章名、三关进度（实心 = 已打下）、已通关打 ✓，当前该打的章外圈金光。
- 已打到的章可点：点卡 = 打下一关（已通关的从第 1 关），点关点 = 指定那关；第一、二章直接出征，第三章起进各章原有选关场景。
- 没打到的章：地图压暗，只露章序 + 锁 +「未解锁」，点了无反应。
- 进度按存档（与天下地图同一套 chapterState）；测试模式（?dev=1）全部开放；测试选关 / DEV 面板入口照旧。
- 键盘：Enter 进当前章、Esc 返回；手柄：打开时焦点在当前章，Ⓐ 进章。
- 底板、卡面、锁沿用行囊那套厚涂素材（panel_bg / tooltip_card / lock_tag），返回按钮用主页的水墨按钮；不画像素、不用程序特效。
