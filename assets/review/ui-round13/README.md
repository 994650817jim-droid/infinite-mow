## 点将（主公）页 `src/ui/HomeHeroPicker.ts`
用户原话：「这里ui也需要调整字体美术不统一」。
- 标题：「点将 · 义军将录」+ 小副标题 →「择 一 良 将」一个大标题（与主页「乱世千军」同字体 TITLE_FONT、同金色 #efd399、同阴影）。
- 提示：从卷轴上（橙红字 + 暗底块，压住第 2、3 张卷轴）移到标题下，象牙白 + 深色描边、无底块；短句「选定即为主公 · 不可更改」；
  再点确认时「再点一次「确认出战」· 定 X 为主公，选定后不可更改」（金色）；主公已定时「主公 · X · 不可更换（其他武将可招为随行）」。
- 页码「第 1 / 3 页 · 共 12 将」→「1 / 3」，放在卷轴与按钮之间；卷轴整体上移 21px，按钮下移 3px，三者互不重叠。
- 翻页箭头同金色 + 描边。卷轴内容不动（选主公时要看兵器、天赋、武艺）。手机版不变。

## 战斗支援弹窗 `src/ui/LegionUI.ts`
用户原话：「下面字体调整字体美术不统一」。
- 字体：「战斗支援」、卡名「刀盾兵 · Lv1」、定位标签、按钮、「跳过」统一 HEADING_FONT（金 / 米色 + 深色描边）；正文（顶部一行、血药说明）统一象牙白。
- 少字：顶部「免费招募 2 人 · 点选兵种卡入队　当前兵力 0」→「免费 ×2 · 兵力 0」；每张卡只留定位标签（近战护卫…），「稳守前线 · 已编入 0 人」去掉，「已编入」改成立绘左上角的朱底数字角标。

- Q 版兵种立绘不动。手机版不变。
