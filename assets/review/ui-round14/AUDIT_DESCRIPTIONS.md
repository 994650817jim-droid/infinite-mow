## 六、建议改代码（文字已按代码写，请主管理决定）

1. **美人计 3 级失效**：代码 `need = meirenji>=3 ? 2 : R.charmNeed`，而平衡把 `charmNeed` 从 3 改成了 2，所以 3 级「只需 2 层即可离间」不再有额外效果。建议 3 级改成「只需 1 次」或换别的奖励（数值归平衡会话）。文字暂时去掉这句。
2. **破围令推开距离**：说明一直写 1/1/1.5 身位，代码是 30/42/54 像素（0.75/1.05/1.35）。若设计本意是 1/1/1.5，请把代码改成 40/40/60。文字暂按代码写 0.8/1/1.4。
3. **槽位名「Boss遗物」 vs 道具「首领遗珍」**：同一样东西两种叫法（行囊筛选已写「遗珍」）。建议统一成「首领遗珍」；SLOTS.relic.name 改名会影响 test-items / test-boss-relics / test-token-slots 的断言，需要道具会话一起改。
4. **「身位」**：全局按 40 像素 = 1 身位换算，建议在新手引导或图鉴里加一句「身位 ≈ 一名士兵的宽度」。
5. **觉醒 / 流派**：卡面已改成「连击系 1/4 · 凑满4个触发觉醒」；觉醒效果本身只在触发时提示。建议在暂停菜单的构筑页加一行「觉醒：同系战法凑满 4 个（或两系各 2 个）后解锁的额外效果」。
