# UI 第 16 轮：战斗内「暂停」改成「设置」（电脑布局 1280×720）

用户原话：「关于战斗的时候 暂停改成设置，然后可以调描边什么的」。

## 改动
- 右上「暂停」→「设置」（手柄显示「☰ 设置」），点开即暂停；Esc / P / 手柄 Start 照旧开关。
- 右上「音效:开」「音乐:开」两颗按钮去掉（挪进设置面板），「行囊」上移顶到原位置。
- 面板「军中设置」两栏：
  - 左栏：继续战斗、分配属性点、行囊 · 换装、战法与宝物、返回营寨 / 退出本关（原暂停功能都在）；
  - 右栏：音乐 / 音效音量滑条，及 ‹ › 切换的各项设置；右下「重看新手引导」。
- 设置项（改了立即保存、战斗中即时生效，主页「军中设置」读同一组键）：
  | 设置 | 键 | 取值 |
  |---|---|---|
  | 敌我描边 | im_iff_outline | 关 / 仅敌人（新）/ 敌我都描（旧 '1'、'0' 照旧可读） |
  | 描边粗细 | im_iff_outline_w | 细 / 粗（新：粗描边线宽加倍，单独生成一套轮廓贴图） |
  | 伤害数字 | im_dmg_numbers | 全部 / 仅暴击 / 关 |
  | 震屏 | im_shake | 强 / 弱（×0.4）/ 关 —— 包一层主相机 shake，所有现有震屏自动生效；键名已发给「新增可玩武将」会话对齐 |
  | 画面清晰度 | im_render_scale | 自动 / 标准 / 高清 / 超清（刷新后生效，面板会提示） |
- 主页「军中设置」的「敌我描边」也改成同样三档（关 / 仅敌人 / 敌我都描），两边同步。
- 手机版不变（右上仍是暂停 + 音效 / 音乐）。
