# UI 第 7 轮：增益图标显示触发进度（只验电脑布局）

用户原话：「关于这种每几次就触发的，玩家可以在左边看到有计数」。

## 样子
- 每个增益图标框下方一条 5 像素的进度条：次数类（≤12 次）逐格填，距离 / 秒数类连续填。
- 满了（下一次就触发）：进度条变亮金，图标框描金呼吸，刚满那一下外框白金闪一次。
- 右下角等级数字、左上角标都不动。
- 悬停提示多一行：「▸ 当前 2/4 刀」「▸ 已移动 2.0/4.0 身位」「▸ 静止 1.6/5.0 秒」「▸ 下次 2.3 秒后」，满了改成「▸ 下一刀重劈」等。

## 覆盖的技艺
- 武学：开山、青龙蓄势（4 刀）、拖刀斩（移动距离）、百步穿杨（静止秒数）、连珠齐射（射击次数）、八阵困军（3 次施法 + 10 秒阵法冷却）。
- 战法：追袭、以战养战（击杀数）、踏风步、迂回袭（移动距离）、沉锋、破阵重击（蓄势 + 冷却）、凝神（静止 + 冷却）、整军（定时治疗）、协击（冷却）。
- 宝物：追魂铃、破军佩（命中数）、走马令（移动距离）、沉锋玉（蓄势 + 冷却）、回军鼓（定时）、点将符（冷却）。
- 觉醒：无双追击、连击 · 追击扩散（命中数）、游龙破军、游击 · 战意破阵（移动距离）、军令（6 秒）；其余觉醒显示冷却。
- 遗物：赤霄火珠（5 秒一次）。
- 武将专属被动层数（马超铁骑、庞统计策、黄忠蓄势…）原本就在左侧「龙 七进七出 0/7」那一行显示，没有重复加。

## 实现
- `src/ui/BuffProgress.ts`：进度类型与格式化。
- `BuildCombat` / `AwakeningCombat` / `CommandBuild` 各加一个只读 `progress()`，只报数，不改任何触发规则或数值。
- 不每帧新建 Text：进度条画在原本每帧重画的框 Graphics 里；提示文字只在那一行内容变化时重排。
