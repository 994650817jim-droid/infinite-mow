# UI 第 8 轮：战斗 HUD「用药」和「行囊」叠在一起（只验电脑布局）

用户原话：「关于ui 用药和行囊叠在一起了」。

## 原因
电脑布局（游戏画面恒为 960×540，窗口 1280×720 / 1920×1080 只是放大）右列：行囊匾在 y 166–196，
用药圆钮中心在 GAME_HEIGHT−340 = 200，命中区 166–234，正好压在行囊上。三种窗口尺寸都一样。

## 改法（只改电脑布局，手机不动）
右列自上而下：暂停 20–82 · 音效 100 · 音乐 132 · 行囊 166–196 · 用药 218–301（含「用药」字）· 加点 316–399 · 护阵 / 出击 412。
用药与加点各下移约 50 像素，命中区互不重叠，都在屏幕内。

## 检查
`tools/ui-round8-hud-overlap.mjs` 量每个控件的命中区：
- 960×540 / 1280×720 / 1920×1080 战斗 HUD：改前「行囊×用药」重叠 → 改后无重叠。
- 暂停菜单（行囊 · 换装等）、行营休整（行囊 · 换装换马 / 回营寨 / 页签）：改前改后都无重叠；行营里战斗 HUD 的用药不透出。

截图里右侧的「DEV 测试面板」只在 ?dev=1 调试时出现，正式游戏没有。
