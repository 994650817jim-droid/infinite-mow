# UI 第 9 轮：测试模式（?dev=1）跟上新系统 · 第一批

用户原话：「dev测试模式也需要适应」。第一批做：测试存档隔离、电脑布局面板、选将、选关。

## 1. 测试存档隔离（最重要）
**改前实测会写正式存档**：`?dev=1` 打一局把武将等级写进 `im_heroes_v1`；面板跳主城会改写 `im_world_v1` 和两个引导标记。

现在（`src/dev/TestSave.ts`，main.ts 第一行引入）：
- 开发构建 + `?dev=1` 时，所有存档读写经过一层「测试存档」：写入 / 删除只进 `imdev:` 前缀的测试键，正式存档和三个存档位一个字节都不动。
- 读取先看测试键、没有再读正式键：测试存档一开始就是当前正式存档的副本，测试脚本预置的正式键照常生效。
- 正式存档在测试模式外被改了（正常游玩或脚本重新预置），旧的测试副本自动作废、跟随新的正式值。
- 面板「测试存档」分组：显示已改几项；「清空测试存档」（全新空档，音量 / 布局等设置保留）、「回到正式存档副本」。
- 任何场景右下角都有「测试存档 · 不写正式存档」角标；面板标题栏也有「测试存档」标签。

## 2. 电脑布局面板（`src/dev/DevPanel.ts`）
- 收起时只是一条约 180px 的标题栏（DEV · 测试存档 · FPS），停在顶部左侧 HUD 与中间计时之间，不压血条 / 计时 / 暂停 / 波次。
- 展开后宽 340px（1920 宽时 380px、字号 13px），整块在屏幕内；各分组点标题折叠，开合状态记住。
- 新分组默认展开：测试存档、选将、选关；原有分组（跳转、时间、成长、Boss、蜀军、主将 / 敌人、结算）默认收起。

## 3. 选将
- 12 名武将任意直接出战（测试模式不受主公锁定）；「同时设为主公」开关、「当前武将设为主公」（只写测试存档）。
