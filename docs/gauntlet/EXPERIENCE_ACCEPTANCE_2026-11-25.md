# 名将连战验收与下一批首领提案

2026-11-25，本地 Windows Chrome 与 Electron。使用隔离存档和本地联机进程。正式原画规格另见同目录的 `ART_REQUEST.md`。

## 本轮可复测的变化

- 同档两场连战使用按局编号的结算凭据。并行首通、重放、关页、切档及旧凭据均有专项。若存档正在进行普通战役，暂存连战战报。战役获胜或撤退后入账，正在显示的战报会自动更新。
- 标准、极限、各自的无尽成绩按单人、双人分别保存。无尽从选择继续后的下一阵开始计数。旧成绩保留在历史记录中。
- 连战领取的跨区将星是本局合法起点，点邻星扣点，本局重开清空。普通战役仍校验武将入口与连线。
- 鬼门、天门及五类结算共用一套排版和按钮。手机与桌面分别适配。正式资源由玩家提供。

## 本地运行

在仓库启动 Vite，将环境变量 `BASE` 设为对应的本地 HTTP 地址。存档测试创建独立浏览器上下文。以下命令均在仓库根目录运行。

```sh
node tools/test-gauntlet-save-races.mjs
node tools/test-gauntlet-campaign-deferred.mjs
node tools/test-gauntlet-deferred-ui.mjs
node tools/test-gauntlet-earned-stars.mjs
node tools/test-gauntlet-natural-standard.mjs . http://127.0.0.1:5286
node tools/test-gauntlet-frame-lifecycle.mjs . http://127.0.0.1:5286 normal-entry 1
node tools/test-gauntlet-frame-lifecycle.mjs . http://127.0.0.1:5286 normal-entry-mobile 1
```

一次正常速度的张飞标准挑战在 22:48 击败神刘备，未复活。赵云的标准与极限成长对照在致命时复血，另行统计，仅用于比较逐阵奖励机会。模拟手机与桌面均出现开场长帧。驱动缓存、浏览器预热和显示器刷新率会影响复测数值。

## P2 首领提案

下列机制仅供下一轮选择，当前游戏仍使用已有招式。

| 首领 | 现有招式 | 建议的打法与反馈 |
|---|---|---|
| 鬼吕布 | 方天锁路、修罗震地 | 锁路后留下一柄可辨认的残戟。下一次赤兔冲锋在起跑时锁定方向，玩家可诱使他撞碎残戟，换取一次近身还击机会，也可侧移避开。残戟由虚转实才参与本次碰撞，始终保留可撤离的一侧。 |
| 神周瑜 | 东风起旗、赤壁落火 | 下一段火势由战旗和飘烬提前报出风向。上风侧留有接近周瑜的通道，下风侧给远程武将留一条绕行路线。二阶段先熄灭旧火再转换风向，让读风与换位成为主要决策。 |
| 神曹操 | 魏武盾势、魏武弓势 | 盾势让正面推进变慢，侧翼可以切入。弓势在号角后令盾兵开口、弓兵分列，玩家可从盾隙接近或从外侧绕射。两势互斥，以举盾、落盾和军旗方向提示切换时机。 |
| 鬼张绣 | 岔影封步、怨影返刺 | 分出两路枪影，仅真身在落脚处扬尘并留下有方向的枪痕。提前移向假身一侧可接近反打，保持距离也能避开回刺。用步态和地面信号同时报招。 |

若批准其中一位，先验证一次基础循环、部曲撤离和双人重连。冲锋、风向与真身由服务器一次锁定并随快照恢复，两端使用同一危险区。测试应包含远近程武将和机关叠加，保证单人失误可以脱险，双人不必牺牲队友换取输出。
