# 名将连战部曲休整试玩提案

第一轮先验证撤离和索敌修正。以下是留待人工试玩选择的实验方案。

| 决策时机 | 玩家选择 | 验证指标 |
|---|---|---|
| 斩将后的现有休整窗口 | 增加一个与当轮补员互斥的“收拢伤兵”选项，仅对仍在场的伤兵生效；已阵亡者保留战损 | 相同余额、阵次和种子下，对照补员队的下阵首领伤害、开战人数与再阵亡人数 |
| 刀盾与重盾 | 护阵时比较挡住普通步兵与及时撤离重击的收益，重盾以替同伴承伤和存活时间评估 | 每百钱承伤、同排友军的死亡来源、躲开后恢复作战的时间 |
| 长枪、精锐戟、轻骑 | 出击允许追击，靠近主将安全边界或预警覆盖时先脱离；按兵种分别记录再接敌时间 | 击中敌方体力的每百钱伤害、危险区停留时间、阵亡前有效攻击数 |
| 弓箭与其他远程 | 检查后排被贴身时能否后撤到仍可射击的位置，重点复查窄路、圆形火区和交叉投射物 | 实际射击距离、被贴身次数、存活人秒输出、死于投射物的比例 |

首轮可用一组明确的实验参数：“收拢伤兵”每阵至多一次，花费当阵一批招兵价的一半（向上取整），按生命比例从低到高选择最多三名斩将时存活的伤兵，每人恢复最多自身最大生命的 20%。无人受伤时不收费。休整和当轮付费补员互斥，守关须先确认继续，双人各付各的钱、只治疗自己的兵。该组参数仅作为 A/B 测试提案，正式数值待试玩。

若大部分损失来自单次致命技能，关间恢复帮助有限，应优先修复对应的危险提示与撤离路线。军团与个人输出的比较同时保留总花费、实际有效伤害、所到阵次和最终结果；零招兵支出的个人局不计算每百招兵钱伤害。
