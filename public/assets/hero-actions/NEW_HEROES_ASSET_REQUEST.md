# 新女将素材需求：孙尚香（吴）、貂蝉（群雄）

**现状（过渡方案，不是独立美术）**：两人的行走图、动作图、立绘都是开机时由黄月英图集**运行时换色**生成的。
孙尚香的绿色衣饰换成赤红，貂蝉的换成粉紫，脸、发型、连弩、背匣都还是黄月英的（见 `src/systems/PlaceholderHeroArt.ts`）。
招牌技特效是程序化的：孙尚香是赤色双环外扩，貂蝉是粉紫花瓣环。主页大幅立绘（epic-home）和水墨立轴（ink-scroll）没有，选将卡用 portrait 墨化显示。

正式图放到下列路径并在 `BootScene` 加载后，过渡生成会检测到纹理键已存在而自动跳过；之后把两人加进 `HOME_ART_HEROES` 和 `HERO_ACTION_FILES`。

## 动作帧规范（与「武将动画尺寸统一」一致）

- 各动作的人物显示比例和行走图一致，同一张图里人物大小不跳变。
- 每格脚底在同一高度，即锚点稳定；动作出格的部分（箭光、花瓣）不改变人物本体的位置。
- 第 5 行（招牌技）：
  - 孙尚香：原地旋身，朝四周连射。
  - 貂蝉：旋身挥双扇，花瓣四散。
- 第 6、7 行：受伤 ×2、胜利 ×2、倒地 ×4。胜利 / 倒地动作：孙尚香举弓 / 长弓落身旁，貂蝉掩扇回眸 / 双扇落身旁。
