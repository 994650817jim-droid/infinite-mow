# 军情事件 · 素材需求（当前全部为程序化 / 复用过渡）

天下地图「军情」事件（名将悬赏 / 流寇袭扰 / 商队护送）上线时没有独立美术，下列为过渡方案与正式素材需求。
素材到位前不阻塞玩法；到位后放在 `public/assets/intel/`，由 WorldMapScene / IntelGameScene 按键名替换。

| # | 用途 | 现在的过渡方案 | 正式素材需求 |
| --- | --- | --- | --- |
| 1 | 地图军情印（赏 / 寇 / 商） | 程序画的彩色圆印 + 单字 | 3 枚印章图标，与城池徽框同画风（漆金描边、手绘质感），透明 PNG，128×128，显示约 30px；赏 = 赤红、寇 = 土黄、商 = 青绿 |
| 2 | 商队护送 · 商车 | 程序画的木车、货包与「商」字旗（静态） | 商车行走图：俯视 3/4 角度、朝北为主（另需朝南），4 帧车轮滚动，透明 PNG，单帧 128×128，与兵种行走表同比例；可加骡马 1 匹 |
| 3 | 商队护送 · 终点 | 复用汜水关场景道具城门（sishui_props_refined 第 0 帧） | 可选：小城城门 / 关隘道具 1 张，透明 PNG 256×256 |
| 4 | 名将悬赏 · 名将造型 | 借用第四章首领图集（颜良 / 文丑 / 淳于琼，按名将名轮换）与其招式 | 每位名将 32 帧首领图集（与第三 / 四章首领同版式 128×128 格）。先做出场频率高的 6 位：许褚、典韦、夏侯惇（曹）、张郃、高览（袁绍）、太史慈（孙） |
| 5 | 流寇 · 寇首 | 精锐西凉兵按黄巾余党配色、放大 1.25 倍 | 可选：寇首行走 + 攻击图（黄巾头巾、朴刀），同兵种表规格 |

验收：替换后地图印在 360–430 宽手机上可辨认；商车与武将同屏比例协调、脚底对齐。
