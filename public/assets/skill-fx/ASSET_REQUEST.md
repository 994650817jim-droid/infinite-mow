# 技艺 / 战法特效 · 素材需求（walk-anim 会话，2026-11-16）

用户规定：「不要再做像素特效了」。拖刀斩、迂回袭、踏风步三套特效改用**手绘 / 厚涂风格的透明序列帧**，
画风参照诸葛亮原版 `public/assets/flame-banner/flame_burst.png`（柔和厚涂、发光边缘、透明底、无描边像素格）。
现有的程序像素版（DraggingBladeFx / FlankFx / WindstepFx，含 ?dragfx / ?flankfx 小样）先不合入、不再改，图到位后整套替换。

## 通用规格
- 透明 PNG（ChatGPT 出图用纯洋红 #FF00FF 底，本地抠成透明；不要投影、不要地面、不要文字）。
- 一张图一条横排序列帧，每格正方形，帧数与格子尺寸见下表；所有帧中心（或标明的锚点）对齐，不要越格。
- 配色：与人物 v2 画风（暗色写实）协调，光效用柔和高光，不要大面积纯色块；**不用青绿色**（用户不喜欢）。
- 尺寸：格子按 256（与 flame_burst 一致）；游戏里按需要缩放，显示 60–180 逻辑像素。
- 文件放 `public/assets/skill-fx/`，原图存 `public/assets/skill-fx/originals/`，文件名加会话前缀 `walk_`。
