# 三选一 / 增益栏图标（upgrade-icons）

来源：ChatGPT 图像生成（用户 Chrome 内「生成游戏UI素材图」对话，2026-11-14），用户确认保存。原图 `originals/sheet-1..4.png`（1254×1254 透明，4×4），构建时不发布。
运行时 64 个 128×128 WebP 由 `node tools/build-upgrade-icons.mjs` 切出（按内容裁边、清除 alpha<20 噪点与格边 3px、等比居中留 6px），清单见 `manifest.json`。旧像素图标保留在 `assets/growth-icons/`、`assets/build/`，未删除。

## 通用要求（每张）
1024×1024 透明背景 PNG，4×4 共 16 个，每个居中于格内并留白，无网格、无外框底板、无文字；写实厚涂暗调史诗感（与画轴立绘同一套美术），清晰深色外轮廓、金铜高光、剪影鲜明，大小/光照/描边一致；用于约 52px 圆形徽章内。
