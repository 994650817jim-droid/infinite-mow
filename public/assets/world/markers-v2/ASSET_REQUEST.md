# 天下地图标记 v2 · 素材需求

当前为程序化过渡美术（src/world/WorldMarkers.ts，Canvas 绘制），拿到正式图后按下表替换，代码只需把贴图键换成文件。
风格：与天下地图底图一致的手绘像素风（16-bit 战略游戏质感），俯视 3/4 角度，暖色光从左上来；参考《三国志》系列的城郭小图标、《全面战争：三国》的据点与名牌。
通用要求：PNG，透明底，四周留 4 px 透明边，不带文字（字由程序叠加），不带势力色（需要染色的部分画成浅灰 / 白色，程序 setTint 着色）。
