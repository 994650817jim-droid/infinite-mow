# 双人联机试玩

联机房间统一进入「名将连战幸存者」。两名玩家用六位房间码组队，各自从本机已解锁的武将中选将，两人可以选择同一位。服务器统一结算战斗，战果独立于单人存档。

连战沿用单人模式的分段抽将规则和现有名将图集。局域网版有 19 位名将、三种带预警的攻击范围。每阵先打兵，26 秒后名将登场。斩将后清场，两位玩家各选一次本局战利品，选完一起进入下一阵。两人各恢复 35% 最大生命，倒地的队友也能在此时归队。打完十阵后，房主可结算或续战无尽。

战斗中靠近倒地队友（72 像素内）持续 10 秒即可扶起，恢复其最大生命的 35%，起身后有 1.8 秒保护。离开范围会中断救援，两人都倒地即结束。斩将选奖励时可查看两人的当前生命和选择状态。

## 本机或同一局域网

使用 Node.js 22.18 或更新版本。从项目根目录运行 `npm ci --prefix server`，然后在两个终端分别运行：

```sh
npm run coop
npm run dev
```

打开 Vite 打印的地址，进入首页「联机」。局域网设备使用 Vite 打印的 Network 地址。房主点击「创建房间」，好友输入房间码；两人到齐后房主点击「并肩出征」。电脑用 WASD 或方向键，手机用摇杆，自动攻击。战斗中任一方退出会结束房间。

## 网页和桌面正式版

GitHub Pages 只发布静态客户端。部署时另启联机服务并将 WebSocket 路径 `/coop-socket` 经 HTTPS 反向代理暴露为 `wss://`，然后在构建客户端时配置 `VITE_COOP_URL=wss://<联机服务域名>/coop-socket`。本地开发无此配置时走 Vite 代理。正式版缺少有效地址时隐藏联机入口。

服务端环境变量：

- `COOP_HOST`：监听地址，默认 `127.0.0.1`。反向代理与服务在同一台机器时可保留默认。
- `COOP_PORT`：默认 `8787`。
- `COOP_ORIGINS`：公网允许的浏览器来源，用英文逗号分隔，以完整来源匹配（例如 `https://994650817jim-droid.github.io`）。配置后关掉开发用的同源允许规则。桌面构建需单独核对 Electron 的来源配置。

`npm test --prefix server` 会在本机的临时端口测试房间、开战权限、共享战场、输入过期和离线回收。
