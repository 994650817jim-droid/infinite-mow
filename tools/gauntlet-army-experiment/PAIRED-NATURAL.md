# 同武将、同种子自然路线对照

从已检出且装好本项目依赖的候选版本启动本机 Vite。在仓库根目录用 PowerShell 运行以下命令，示例使用本机 5173。证据目录应使用新的路径，避免覆盖先前采样。

```powershell
$env:GAUNTLET_ARMY_EVIDENCE = Join-Path (Get-Location) 'output/army-natural-r1'
$env:GAUNTLET_ARMY_ROUTE = 'standard'
node tools/gauntlet-army-experiment/run-pairs.mjs . http://127.0.0.1:5173
node tools/gauntlet-army-experiment/analyze.mjs
node tools/gauntlet-army-experiment/compare-naturals.mjs
```

启动器运行四个独立 Chrome 会话。若机器资源有限，在最后一个参数分别指定 `zhangfei` 或 `huangzhong`，每次只并行运行同一武将的两个策略。源文件与运行的 Vite 必须属于同一个检出版本。每场按原规则抵达结算或自然战败。原有选牌暂停、命中顿帧、掉落、升星资格、支付、招募、首领出场与受伤结算均沿用游戏实现。两种策略都用护阵、同一套移动、选分支、用药及通常的副将优先级，救命复活卡在两组都排除。普通升级中遇专属军团卡时，军团策略会优先于常规副将选择。

| 策略 | 星图与选卡 | 招兵 |
|---|---|---|
| 军团 `army` | 优先统御区可点星。优先已有的军团钱袋、统御星、说明含部曲、军阵、统御、招兵、援军、亲兵的卡。无合适选项时沿用常规选牌。 | 在招兵开放、存活部曲少于 25 且钱够时按当阵价格购买。 |
| 个人 `personal` | 优先力量区可点星。军团选项降到最后，常规优先级含紧急疗伤、未满额副将、本命武器与移动。 | 不主动用钱招兵。强制或无替代的合法奖励仍按原规则执行。 |

程序核对每一对的开局核心状态、三阶段完整候选首领名单、11 个相关源码文件校验值、种子、军令和路线。战斗由真实时钟推进，选牌和招兵也会消费游戏随机数。共同种子保证起始名单一致；实时帧、移动、后续随机消费和事件时序会分化，结果属于策略组合的个案对照。

### 弹种与受击

在场景投射物发射时记录发射分支、敌人种类、出生编号与特性，在池对象复用时覆盖旧标签。子弹命中时再记录实际贴图、是否瞄准主将及目标体力变化。按发射点区分普通弓箭、特性弓弩箭、基础首领瞄准法球、首领环射法球和张角符弹。特性箭再按实际 `trait.kind` 细分。箭身贴图颜色不决定发射者；张角回退到法球贴图时仍按符弹分支记。场景投射物撞到主将也单独保存，包括被无敌帧等格挡的零体力损失。

神鬼首领控制器按实际命中的招式名另记。地面落点按箭雨、落雷、陨石区分；只有真实命中同袍才产生战损。其余首领或环境入口保留原记录器大类。既有证据若只有 `projectile` 或阵中人口差，回放不能复原旧弹种或旧击杀者，应保留未知。

`army.json` 保存逐士兵的出生、扣血、阵亡和实际输出。`summary.json` 汇总每兵种、逐阵战损与带右删失的寿命中位数。`paired-natural.json` 保存按武将对齐的终局、伤害、兵种、弹种、选卡与成本。每百钱输出分子为部曲打掉的实际敌方体力；敌盾另列。无付费招募时该指标为 null。
